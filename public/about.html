ABOUT

Software shaped by data and useful problems.

I’m Subramanya Trishank Reddy Mukkamalla, a Computer Science and Engineering graduate specializing in Data Science. I work across machine learning, data applications, and full-stack development.

What I build

The projects here range from connected devices to web applications. MedConnect explores remote health monitoring with ESP32 and MAX30102 sensors. Potato Disease Classification applies a convolutional neural network to leaf images. InsightX is an analytics dashboard for sales and customer metrics. The live project list links to my public GitHub repositories.

How I approach a project

I like working through the whole path from a concrete question to a usable result: prepare the data, choose a method that fits the problem, and make the output understandable in an interface. I’m currently interested in generative AI and retrieval-augmented generation, alongside backend and data engineering.
